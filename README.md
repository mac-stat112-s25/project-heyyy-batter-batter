
# Heyyy Batter Batter: How Park Factors Influence Offensive Metrics

This repository contains the final project for STAT 112 at Macalester College.
Our analysis explores how Major League Baseball stadiums impact offensive performance metrics by investigating key physical characteristics known as **park effects**. 
We focus on three main factors: **elevation**, **extra outfield distance**, and **home run park factor**,
and how they relate to player and team offensive statistics like **home runs** and **wOBA** (weighted on-base average).

## Software Version

- R version 4.4.2 (2024-10-31)

## How to Run This Project

- Clone this repository:
```bash
   git clone https://github.com/mac-stat112-s25/project-heyyy-batter-batter.git
   
- Open the project in RStudio.

- Ensure all required packages are installed (see below).

- Make sure the CSV datasets are placed in the appropriate data/ folder if not already there.

- Render the website by opening the .qmd file and clicking "Render" in RStudio.

- The final website will appear in the _site/ folder and can be viewed in any browser.
